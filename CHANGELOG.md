# Changelog

All notable changes to this project are documented here. Format: [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). Versioning: [SemVer](https://semver.org/).

## [0.2.0] - 2026-10-08
### Added
- SEO-friendly README with a skill table, an install guide for Claude Code, Claude Cowork and Codex, and example prompts
- `docs/`: skills reference, migration guide (Codex, Cursor, Copilot, Windsurf → Claude), MCP server guide, workflow recipes, FAQ
- `.codex-plugin/plugin.json` manifest for Codex compatibility
- `scripts/build-plugin.sh` to package a `.plugin` file
- CONTRIBUTING guide, issue and PR templates

## [0.1.0] - 2026-10-07
### Added
- First release: 16 iOS skills (7 original, 9 adapted from openai/plugins) and the XcodeBuildMCP, Xcode, RevenueCat and Mobbin MCP servers
